# BubbleID Project

This project aims to train a Detectron2 instance segmentation model to detect and classify bubbles from videos and images. It relies on the Detectron2 library for the training pipeline and provides scripts for data analysis, augmentation, and model evaluation.

This repository is dedicated to the **training** pipeline. It allows students and researchers to train custom models, perform k-fold cross-validation, and optimize hyperparameters.

This project is part of an improvement of the original BUBBLEID code developed by Dunlap et al. ([see](https://github.com/cldunlap73/BubbleID)).

## Project Structure

- `dataset/`: Directory where you must place your images and LabelMe JSON annotations before training.
- `Test_augmentation_*/`: Output directories automatically generated by the training script, containing trained weights, configurations, and evaluation metrics.
- `kfold_run/`: Output directory for standard cross-validation runs.


## Main Scripts' Description


| File/Script                                    | Quick Description |
|------------------------------------------------|------------------|
| **test_entrainement_decoupe.py**               | Main script! Launches Detectron2 training with K-Fold cross-validation and Albumentations. |
| **check_gpu.py**                               | Checks if your GPU is compatible with Automatic Mixed Precision (AMP) for faster training. |
| **check_class_balance.py**                     | Analyzes LabelMe annotations to check the balance between classes (detached, attached, etc.). |
| **analyse_taille_bulles.py**                   | Computes bubble size distribution to optimize the anchor generator sizes for the model. |
| **find_meilleur_fold.py**                      | Scans the K-Fold output directories to identify the best performing fold sub-model. |
| **plot_learning_curves.py**                    | Plots the training loss and validation AP curves from the `metrics.json` file. |
| **create_background.py**                       | Generates a background image by calculating the median pixels across multiple frames. |


## Installation
(La procedure d'installation est reprise de  https://github.com/cldunlap73/BubbleID)

First download and install the latest [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)


Install [Python](https://www.python.org/downloads/)

Create a new environment with python 3.10, we used [anaconda](https://www.anaconda.com/download)

```bash
conda create -n bubbleid python==3.10
conda activate bubbleid
```

Install [git](https://git-scm.com/install/)

Update dependencies:
```bash
pip install --upgrade pip setuptools wheel
```
Install [pytorch](https://pytorch.org/get-started/locally/) (Make sure cuda version matches if using gpu):
```bash
# CUDA 12.6
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu126
# CUDA 12.8
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
# CUDA 13.0
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu130
# CPU only
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
```
Install [detectron2](https://github.com/facebookresearch/detectron2):
```bash
pip install git+https://github.com/facebookresearch/detectron2
```
Install Additional Dependencies:
```bash
pip install numpy==1.23 opencv-python filterpy super-gradients
```
Git clone the repository
```bash
git clone https://github.com/YOUR_GITHUB_NAME/BubbleID_training.git
cd BubbleID_training
```
